## 浏览器验收

Playwright CLI 驱动真实 Chromium 页面，未 mock API。截图见 [页面说明](frontend.md)。实测记录如下：

| 操作 | 实际观察 |
|---|---|
| 管理员登录 | 用户列表与管理员标记正确 |
| 新建系统、权限、用户、角色 | 保存后列表重新查询并出现新记录 |
| 用户编辑、设置密码、停用 | 名称/状态更新；新密码可登录；停用后旧会话 401 |
| 空用户名 | 浏览器 validationMessage 为“请填写此字段。” |
| 重复用户名 | 后端 409，显示中文冲突消息 |
| 短密码 | 前端提示至少 8 字符及 72 字节限制，不提交成功 |
| 双标签页回收 | 同一个普通用户会话：200 → 回收一个仍 200 → 回收最后一个 403 |
| 角色权限回收及角色停用 | 勾选/启用状态保存并刷新 |
| 主动注销并探测旧 JWT | 401，返回登录页 |
| 账号被管理员停用后刷新 | 401，清除当前身份并提示重新登录 |
| 最终产物重启 | 原数据消失；重新初始化管理员后角色列表为空，新建角色成功 |
| 390×844 登录页 | 表单和提示可读，无水平裁切 |

验证中的 401/403/409 在浏览器网络控制台中属于预期 HTTP 错误；不将它们视为 JavaScript 异常。首轮 favicon 404 已通过内嵌空图标修复，最终产物重新加载未出现该错误。

## 风险与未验证内容

- MySQL 全量脚本、管理员字段迁移、锁语义和字符排序规则：未运行。H2 的结果不能替代 MySQL。
- 多实例同时首次创建管理员：没有分布式互斥；仅支持单实例执行初始化。共享数据库会话的设计不等于真实多实例验收。
- 服务器部署、HTTPS、持久化重启、生产限流、备份恢复、真实业务接入：未验证或未实现。
- 前端所有网络失败分支、所有浏览器和读屏器：没有全面自动化测试；只记录实测项目，不宣称全兼容。
- 列表当前无分页/搜索；权限计算逐角色查询，适合小规模课程演示，未做大数据性能保证。
- 当前权限回收作用于后续请求，不强制中断已经开始的请求。
- 不记录持久化操作审计，不提供密码找回、自动过期会话清理或多个管理员生命周期管理。这些不影响本次限定的单管理员 RBAC0 演示，但生产使用前需另行设计。
