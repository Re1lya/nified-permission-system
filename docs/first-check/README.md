## 已完成、未完成、待验证

已完成：首次检查的界面、数据库设计、RBAC0 功能实现、最小管理边界、本地可重复演示、测试及检查材料。管理员可以配置全部演示数据，普通用户不能直接访问管理 API。页面成功写入后重新查询数据。

未实现且不属于此次范围：RBAC1 角色继承、RBAC2 角色互斥、部门/租户管理范围、OA 审批、HR 同步、Excel 导入、真实报销系统。页面没有分页/搜索，适合小规模课程数据，不作为大规模生产管理端交付。删除接口已有后端测试，但网页优先提供可逆的停用和授权回收，不提供删除按钮。

未验证：真实 MySQL 建表/迁移与并发行为、服务器部署、重启持久化、多实例、网络安全与负载能力。本次 H2 与同进程独立验证器测试不能替代这些验收。
