== 本次修正

* 旧完整 ER 图片只有 25 张表；现已根据当前 MySQL DDL 重新生成 38 张表、26 个物理外键的完整图和四份分域图，并提供 SVG、PNG 和 Mermaid 源码。
* 修正账号、员工档案、权限明细、岗位角色的一对一上限，以及部门上级和负责人可空关系；补充主键、唯一键、外键及逻辑关联的说明。
* 停用基于历史 H2 快照的旧绘图脚本，防止覆盖当前图。新生成脚本以同一份 MySQL DDL 为输入。
* 为旧版 RBAC 设计增加历史标识。四份 Word 为 2026-10-22 快照，当前检查文档以本目录 AsciiDoc 为准。
* 修正导入预览接口的 OpenAPI：三个文件仅作为 multipart/form-data 上传字段，不再重复声明为 query 参数。Apifox 已同步 1.4.2，界面显示新增 0、修改 1；项目仍为 98 个接口、25 个模型，保留 HTTP 检查环境。
* 需求用例表区分 HR 创建随机初始密码与 Excel 导入创建无密码账号，避免与当前导入实现不一致。
